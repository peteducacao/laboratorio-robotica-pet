Como usar o painel

Um guia simples para administrar o PETQuiz.

1. Início

Use os atalhos para acessar as perguntas, abrir o jogo e alterar as configurações. Os botões de PETQuiz e Gabarito permitem liberar ou bloquear os acessos de forma independente.

2. Banco de questões

Toque numa pergunta para abrir o editor. Mude enunciado, alternativas, gabarito, categoria, assunto e situação ativa. Use Salvar pergunta após editar. Também é possível criar novas perguntas ou excluir as que não serão utilizadas.

3. Categorias e requisitos

Crie, renomeie ou exclua categorias e assuntos. Os que já são utilizados por perguntas precisam ser desvinculados antes da exclusão. Categorias e requisitos ficam disponíveis para escolha no editor.

4. Configurações do jogo

Escolha quantas perguntas e quantos bônus aparecerão por partida. Os sete desafios bônus existentes continuam fixos e não têm editor individual.

5. Salvar e atualizar para todos

O token usado para entrar também permite publicar. Após salvar uma pergunta ou mudar uma configuração, aguarde o aviso Publicado para todos!. Em caso de falha, use Publicar agora. O backup é opcional.

6. Senha do painel

O token GitHub substitui a antiga senha do Admin. Ele é guardado somente nesta sessão do navegador e não é incluído nas perguntas ou no site. O mesmo token pode atender ao catálogo se tiver acesso aos dois repositórios. Use Sair para encerrar a sessão.
